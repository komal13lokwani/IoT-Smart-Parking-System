# IoT Based Smart Parking System

## 📌 Overview
This project detects parking slot availability using an IR sensor and updates the status on a cloud dashboard in real time.

## ⚙️ Components Used
- ESP8266 (NodeMCU)
- IR Sensor
- LED
- Blynk IoT Platform

## 🔌 Working
The IR sensor detects the presence of a vehicle.

If detected:
- LED turns ON
- Blynk shows "Occupied"

If no object:
- LED turns OFF
- Blynk shows "Empty"

## ☁️ Platform Used
Blynk IoT Cloud

## 📊 Features
- Real-time parking status
- Cloud monitoring
- Simple and efficient system

## 🚀 Future Scope
